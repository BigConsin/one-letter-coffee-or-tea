A Python program that writes exactly one letter, B for tea, and nothing else to /output/entry.txt: no word, no explanation, no punctuation and no trailing newline, so the file is a single UTF-8 character that passes the one-character gate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
